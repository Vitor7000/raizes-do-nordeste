Política de Privacidade

Última atualização: 11 de setembro de 2026. Este documento explica, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD), como o site e o totem de autoatendimento do Raízes do Nordeste coletam, usam e protegem os dados pessoais dos titulares (clientes e visitantes).

1. Controlador dos dados

O controlador dos dados pessoais tratados por este site é a rede de restaurantes Raízes do Nordeste. Dúvidas, solicitações ou reclamações sobre privacidade podem ser enviadas para privacidade@raizesdonordeste.com.br, nosso canal de atendimento ao titular de dados (DPO/encarregado).

2. Quais dados coletamos

  • Dados de cadastro: nome, e-mail, telefone e senha (armazenada apenas neste protótipo local; em produção seria armazenada com hash e nunca em texto puro).
  • Dados de pedido: itens do carrinho, unidade escolhida, endereço de entrega e forma de pagamento informada no checkout.
  • Dados de uso: unidade selecionada, itens visualizados/favoritos e pontos do programa de fidelidade.
  • Dados de pagamento: neste protótipo, os dados de cartão informados na página de pagamento são simulados e não são enviados a nenhum servidor — eles existem apenas para fins didáticos da interface.

3. Onde os dados ficam armazenados

Por se tratar de um protótipo acadêmico sem back-end, todos os dados acima (usuários, pedidos, carrinho, pontos de fidelidade e o próprio consentimento) são gravados apenas no armazenamento local do navegador (localStorage) do dispositivo do usuário. Nenhuma informação é enviada para servidores externos ou compartilhada com terceiros. Em uma versão de produção, esses dados seriam armazenados em um banco de dados seguro, com criptografia em trânsito e em repouso.

4. Finalidade e base legal do tratamento

  • Execução de contrato: processar pedidos, calcular totais e exibir o cardápio correto para a unidade escolhida.
  • Consentimento: manter a sessão do usuário, lembrar o carrinho entre visitas e enviar comunicações do programa de fidelidade e de promoções.
  • Legítimo interesse: métricas internas de uso do cardápio e das promoções para melhorar o serviço.

5. Compartilhamento com terceiros

Na página de pagamento, os dados informados seriam, em produção, compartilhados apenas com um Sistema de Pagamento Externo (gateway de pagamento/adquirente) estritamente para autorizar a cobrança — este é o ator "Sistema de Pagamento Externo" descrito no diagrama de casos de uso do projeto. Não vendemos nem compartilhamos dados pessoais para fins de publicidade de terceiros.

6. Direitos do titular

Conforme o art. 18 da LGPD, você pode solicitar, a qualquer momento:

  • Confirmação da existência de tratamento e acesso aos seus dados;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários;
  • Portabilidade dos dados a outro fornecedor de serviço;
  • Eliminação dos dados tratados com base no consentimento;
  • Revogação do consentimento a qualquer momento.

Você pode apagar seus dados salvos neste protótipo a qualquer momento limpando os dados do site no seu navegador, ou pelo botão "Sair" no menu, que remove a sessão ativa.

7. Retenção dos dados

Os dados de cadastro e pedidos são mantidos enquanto a conta estiver ativa ou pelo prazo necessário para cumprir obrigações legais/fiscais. Dados de navegação sem cadastro (ex.: carrinho de convidado) permanecem apenas no dispositivo do usuário.

8. Cookies e armazenamento local

Utilizamos o localStorage do navegador (não cookies de rastreamento de terceiros) para lembrar login, carrinho, unidade selecionada e o próprio aceite desta política. Você pode limpar esses dados nas configurações do seu navegador a qualquer momento.

9. Alterações desta política

Esta política pode ser atualizada periodicamente. Alterações relevantes serão sinalizadas nesta página com nova data de atualização.
